# Claire Dupont Personal Page

A static, GitHub Pages-ready page for a lingerie designer and boutique owner, with a local hero image and lightweight animation.

## Publish on GitHub Pages

1. Create a new GitHub repository.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder.
3. In GitHub, open **Settings > Pages**.
4. Set the source to the `main` branch and the root folder.
5. Save, then open the Pages URL GitHub provides.

## Edit

- Update the WhatsApp link in `index.html` if the contact number changes.
- Replace `assets/claire-hero.png` if you want a different hero image.
