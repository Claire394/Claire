# Claire Dupont Personal Website

A polished one-page personal website for Claire Dupont, built as a static site for easy GitHub Pages deployment.

## Files

- `index.html` - page structure
- `styles.css` - responsive visual design
- `assets/claire-office-hero.png` - optimized desktop homepage background portrait
- `assets/claire-personal-photo.png` - mobile homepage portrait
- `assets/claire-office-hero-original.png` - backup of the original landscape photo

## GitHub Pages

Upload these files to a GitHub repository, then enable GitHub Pages from the repository settings. Use the root folder as the publishing source.
